YouTube Shorts Auto

最終更新日：2026年10月10日

1. ツールの目的と利用対象

本ツールは、運営者が自身の英語学習動画を制作し、 自身のYouTubeチャンネルに投稿するための個人用ツールです。 一般利用者の登録は受け付けていません。 運営者は本ポリシーを確認・同意したうえで利用します。

2. 取り扱う情報

  • Google OAuthで発行されるアクセストークンと更新トークン
  • 投稿する動画、タイトル、説明文、公開設定
  • YouTubeから返される投稿済み動画のIDとURL
  • 台本生成の指示文、生成された台本、音声、字幕画像

Googleアカウントのパスワードは取得しません。 現在要求するYouTubeの権限は動画アップロード用の youtube.uploadです。視聴履歴や登録チャンネル一覧を 取得する機能はありません。

3. 利用目的と外部サービスへの送信

本ツールはYouTube API Servicesを利用します。 認証情報はGoogleでの認証と投稿に使用し、 動画と投稿情報をYouTubeに送信します。

台本生成の指示文はGemini APIへ、 読み上げ用の文章はGoogle Cloud Text-to-Speechへ送信します。 YouTubeの認証トークンをこれらの生成サービスに送信する 処理はありません。

取得したGoogleユーザーデータを販売したり、 広告配信やAIモデルの学習目的に利用したりしません。

4. 保存と管理

認証情報と制作物は運営者のMacおよびGitHubの非公開リポジトリの 実行環境で取り扱います。YouTubeのOAuth認証情報とGemini APIキーは GitHub Actions Secretsに保存し、処理時に実行環境へ渡します。 Google Cloudへの接続には短期の認証情報を使います。 完成動画・台本・投稿結果は非公開のArtifactsに最大7日保存します。 重複防止用の実行記録と使用済み英語表現も非公開リポジトリに保存します。 認証情報は公開リポジトリに掲載しません。

投稿処理で取得したAPIデータは必要な期間に限って保存し、 運営者が30日以内に更新または削除します。 不要になった認証情報は削除します。 制作した台本・音声・動画は、運営者が削除するまで保存します。

5. 認証の解除とデータ削除

Googleアカウントの接続管理画面 から、本ツールへのアクセスを取り消せます。

利用を終了する場合、運営者は実行を停止し、 アクセスを取り消したうえで、Mac内のtoken.jsonと、 投稿結果を保存したyoutube_upload.jsonおよびその複製を 速やかに、遅くとも7日以内に削除します。 制作物も不要であれば、保存先から削除します。

Mac内のファイルを削除しても、YouTubeに投稿済みの動画は 削除されません。投稿済み動画はYouTube Studioから 別途削除してください。

クラウドでの利用を終了する場合は、GitHub Actionsの実行を停止し、 Googleでの認証を取り消したうえで、GitHubのSecrets、保存済みArtifacts、 該当する実行ログとバックアップも速やかに、遅くとも7日以内に削除します。

6. この説明サイトについて

本サイトには独自の広告、アクセス解析、Cookieを使った 追跡機能を設置していません。サイトの配信にはGitHub Pagesを 利用しており、配信事業者がIPアドレスなどのアクセス情報を 自社の方針に従って処理する場合があります。
